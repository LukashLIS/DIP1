# Локальный перевод озвучки видео на русский

Этот проект — каркас Python‑приложения для локального перевода озвучки видео на русский язык с поддержкой GPU. Он описывает полный конвейер и даёт структуру кода для интеграции общедоступных ИИ‑моделей.

## Возможности
- **Диаризация** (разделение по спикерам)
- **ASR** (распознавание речи)
- **Осмысление текста** (упрощение/нормализация перед переводом)
- **Перевод**
- **Генерация озвучки**
  - сохранение голоса/интонации/таймингов (при наличии VC/TTS)
  - либо 1–2 базовых голоса + последующая конверсия голоса
- **Сборка** в оригинальное видео

## Структура
- `app/cli.py` — CLI
- `app/config.py` — загрузка конфигурации
- `app/pipeline.py` — оркестратор шагов
- `app/schema.py` — общие dataclass и ошибки
- `app/steps/` — шаги диаризации/ASR/перевода/TTS/отчёта
- `app/ffmpeg_utils.py` — обвязка ffmpeg
- `config.example.yaml` — пример конфигурации

## Быстрый старт
1. Установите зависимости и ffmpeg.
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
2. Скопируйте конфиг:
   ```bash
   cp config.example.yaml config.yaml
   ```
3. Запустите:
   ```bash
   python -m app.cli --config config.yaml --input ./input.mp4 --output ./out
   ```

## Рекомендуемые модели (пример)
- Диаризация: `pyannote.audio`
- ASR: `faster-whisper` или `whisperx`
- Нормализация/осмысление: `transformers` (LLM) или локальная LLM
- Перевод: `transformers` (NLLB/M2M) или LLM
- TTS: `coqui-tts`/`XTTS` или `StyleTTS2`
- Voice conversion: `RVC`/`So-VITS`

## Примечания
- Этот каркас не скачивает и не встраивает модели автоматически.
- Для 5070 Ti (CUDA) используйте сборки PyTorch с поддержкой вашей версии CUDA.
